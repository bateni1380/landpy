# Tutorial visuals

- `project-map.png`: project architecture and the crop → edit → retrace loop.
  Regenerate from the repository root with `python tutorials/assets/render_project_map.py`.
- `face-preview.png`: the three-panel output of notebook 8’s “See the complete AR
  result” cell. Notebook 1 embeds this and the project map as attachments so its
  opening visuals travel with the notebook. If the effect changes, refresh the
  preview and its notebook attachment from the newly executed output.

The portrait preview inherits the provenance limitations documented in
`examples/assets/README.md`. It is not the generated marketing cover, which is
stored separately in `docs/assets/`.
